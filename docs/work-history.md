# 대화별 작업 기록

대화 아래 작업 바 위의 **작업 기록** 버튼에서 작업 폴더와 생성형 AI 사용 내역을 본다.
본채팅, 추가 채팅 창, 멀티 패널과 팝아웃이 같은 컴포넌트와 대화 저장 형식을 사용한다.

- 작업 폴더: 대화의 작업 디렉터리, 실제 변경 파일의 부모 폴더, 생성 결과의 로컬 경로.
  존재하는 폴더만 표시하며 클릭하면 Windows 파일 탐색기로 연다.
- 본문의 인라인 코드/Markdown 링크로 표시된 로컬 경로도 존재 여부를 확인해 버튼으로 바꾼다.
  파일은 기존 파일 보기로 열고, 옆 폴더 아이콘은 파일 탐색기를 연다.
- 생성 내역: 서비스, 모델, 프롬프트, 실행 시각, 요청 상태, 호출 소요 시간, 작업 ID,
  결과물, 실행 설정과 서비스가 보고한 크레딧/토큰/달러 사용량.
- 프롬프트 복사, 검색, JSON 내보내기를 제공한다. 기록은 대화 스냅샷과 함께 저장된다.

## 수집과 수치의 의미

`GenerationCapture`가 Claude와 Codex의 MCP 도구 입력/결과를 표시용 요약 전에 받는다.
Tripo make, ComfyCloud partner_generate/run_template/submit_workflow/submit_batch 등의
생성 요청을 기록하고, task_get/task_wait/get_output 등은 서비스와 작업 ID로 기존 건을 갱신한다.
잔액/이력 조회는 생성 건으로 기록하지 않는다. 하위 에이전트의 MCP 호출도 같은 흐름으로 들어온다.

새 기능이 적용된 뒤의 구조화된 MCP 호출부터 수집한다. 과거 대화의 요약된 도구 행에는
원래 인수가 없으므로 프롬프트나 사용량을 복원했다고 주장하지 않는다.
임의의 셸/외부 스크립트가 직접 서비스 API를 호출하는 경우까지 자동 추정하지 않는다.

요청 접수와 작업 완료를 구분한다. 실행 중 앱을 종료한 기록은 복원 시 결과 확인 필요로 표시한다.
조회 실패로 이미 완료된 생성을 실패 처리하지 않는다. 누락 사용량은 **미제공**,
명시적으로 보고된 0은 **0**이다. 견적/예상 비용과 계정 잔액 차이를 실제 과금액으로 사용하지 않는다.
복수 작업 배치/체인의 개별 사용량을 전체 비용으로 표시하지 않는다.

Tripo CLI 0.3.1의 make 결과에는 크레딧이 누락된다. 완료된 단일 작업은
`GET /v3/tasks/<task_id>`로 `credits_consumed`를 한 번 보완한다. 생성 요청은 추가하지 않는다.
서비스가 토큰을 보고하지 않으면 대화 모델의 Claude/GPT 토큰을 서비스 사용량에 합산하지 않는다.

인증 헤더/키/비밀번호와 이미지 base64는 실행 설정에서 제외한다. 큰 인수는 128,000자까지
보관하고 상세 보기에 생략 여부를 표시한다. 원본 서비스 결과 전체나 인증 토큰을 기록하지 않는다.

## 검증

- `node scripts/poc-work-records.mjs`: 실제 수집기 → 대화 reducer → 저장/복원 리플레이.
  중복 조회, 0/미제공, 오류, 견적 제외, 다른 대화의 늦은 이벤트, 한글·공백 경로,
  Tripo 사용량 보완을 검증한다. 유료 요청 0회.
- `node scripts/poc-work-history-ui.mjs`: 실제 WorkBar/Markdown/preload를 숨긴 Electron 창에서
  검사한다. 폴더 버튼 IPC, 기록 상세, 390px 레이아웃, Escape/포커스 복원, 잔액과 새로고침 확인.
  전제: 앞의 리플레이 결과, 최신 빌드 preload, 잔액 검증 결과 파일이 존재해야 한다.
- 화면 및 결과: `.dev-home/work-records-verification/`.
